# 全息核心演示

入口：`MGPU.srcs/sources_1/new/top.v`。

保留校准图、原 RGB 三角形和场景停留时间，第三阶段循环展示全息核心：
- 原有 64 步 Y 轴旋转、固定 X 轴倾斜和背面剔除。
- 每个可见面先画深蓝底面，再画缩小至 3/4 的渐变面板。
- 面板共享顶点使用一致的 RGB332 颜色，利用现有 GPU 做颜色插值。
- 按角度周期切换高光色；这是演示配色，不是新增物理光照计算。
- 场景入口绘制外围刻度、角标与三层底座，之后只清除和重绘核心区域。

命令编号：0–1 清除；2–25 为六个面的底面与面板，每面四个三角形；26–57 为静态 HUD 的十六个矩形。不可见面和零面积三角形跳过。HUD 固定布局按默认 CUBE_HALF_SIZE=96 设计；增大尺寸时需要同步调整装饰位置，避免清除区域覆盖装饰。

保留本次开始时用户的 GPU 完成握手；未改动 mgpu、rasterizer、shader、fifo、regs、vga 或时钟约束。新增面板增加绘制像素，本演示不包含升频或并行 shader 优化。RGB332 渐变会呈现离散色阶。

验证输出位于 `out/holo/`。hologram_preview.png 使用 RTL 导出的 45° 绘制命令和软件定点插值参考生成，不是实板截图。

- 顺序测试通过全部 64 个角度及回绕、投影、剔除、停留时间和握手，949 条命令。
- 实际 GPU/VGA 校准图和原三角形通过；两帧核心专项仿真通过 56 条命令、570705 次写入、3856370 次实时扫描读取。
- 校准图、原三角形、核心角度 0/1 的每帧全部 307200 像素，与独立定点插值参考一致。
- 核心专项测试预填 A5 背景，验证首次完整清除、后续局部清除及 HUD 保留。

- 下载文件：out/vga_current/nexys_a7_vga.bit；尚未实板验证。
